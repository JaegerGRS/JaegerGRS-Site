Rig API · Install

Deploy, pair, embed.

The panel script lives on your Worker, not on your website, so the install has a few steps that matter. They are written here in the order to do them.

Honest status. The Worker is the one that runs this site and has not yet been split into a standalone package. Deploying it to your own Cloudflare account needs Wrangler and some comfort with configuration, which is what the done-for-you option covers. Cloudflare's own plan limits and charges apply to your account.

Order of work

Six steps.

  1. Deploy the Worker to your Cloudflare account with the bindings below.
  2. Set RIG_SETUP to open and RIG_EMBED_ORIGINS to your website's address, then deploy again.
  3. Run JaegerRigAgent.exe on the PC to show, enter your Worker address and press Get key from site.
  4. Remove RIG_SETUP and deploy again, so nobody else can pair.
  5. Add the script tag to your website using the full Worker address.
  6. Open your website. The panel shows Online within a few seconds. Switch the PC off and check it shows Offline after about 25 seconds.

1 and 2

Worker settings.

[[durable_objects.bindings]]
name = "RIG_HUB"
class_name = "RigHub"

[[migrations]]
tag = "v1"
new_sqlite_classes = ["RigHub"]

[vars]
RIG_SETUP = "open"                          # remove after pairing
RIG_EMBED_ORIGINS = "https://your-site.example"
  • RIG_EMBED_ORIGINS takes a comma-separated list of website origins, or * to allow any. It is off by default. Without it, browsers block the panel on your website.
  • Prefer a Cloudflare secret named RIG_TOKEN (32+ characters) if you would rather set the key yourself. It takes priority and switches off site-generated keys.

5

The script tag.

<div data-jgrs-rig></div>
<script src="https://YOUR-WORKER-DOMAIN/embed/rig-embed.js" defer></script>
  • Use the full address. A relative path such as /embed/rig-embed.js resolves to your own website, where the file does not exist, so nothing appears.
  • The optional div marks where the panel goes. Without it the panel floats in the corner. Options on the script tag: data-title, data-theme="light" and data-api.
  • If your website sets a Content Security Policy, allow script, style and connect requests to the Worker domain.

Tray icon

Reading the colours.

  • Green: online and reporting.
  • Orange: cannot reach the site, or the site has no key yet. Retrying.
  • Red: the key was rejected. Choose Change key and pair again.
  • Grey: starting up.

Testing

What was tested.

  • Tested on 15 October 2026: a local Worker on one port and a separate website on another. Without RIG_EMBED_ORIGINS the browser blocked the data request. With the website listed, the panel loaded and showed live values. A relative script path was not used because it cannot resolve to the Worker.
  • Not tested: a deployment on a fresh Cloudflare account, other browsers, or customer websites with strict Content Security Policies.

Questions

Install questions.

What happens when my PC is off?

The panel shows Offline after about 25 seconds without an update. It keeps the last known specs, labels them as such and hides load and temperature.

Why does the panel not appear on my website?

Check three things: the script address is the full Worker address, your website is listed in RIG_EMBED_ORIGINS, and your website's Content Security Policy allows the Worker domain.

Is it safe to leave setup open?

No. Remove RIG_SETUP once the PC is paired. While it is on, anyone who finds the claim address first can pair, and with the rotate setting they can replace your key.
