Rig API · Install

One line. No coding.

Add a single tag to your page and the live panel appears by itself. It updates every few seconds and works on phones and TVs.

On your site

Add the tag.

<script src="https://YOUR-WORKER-DOMAIN/embed/rig-embed.js" defer></script>
  • Want it in a certain spot? Add <div data-jgrs-rig></div> where it should go. Otherwise it floats in the corner.
  • Replace YOUR-WORKER-DOMAIN with the domain your Rig API Worker runs on (a relative path would point at your own site and fail). Options on the tag: data-title, data-theme="light", data-api.

On your PC

Pair the app.

  • Run JaegerRigAgent.exe. It lives in the tray and can start with Windows.
  • Click Get key from site. No key to copy or paste.
  • Your PC appears on the panel within a few seconds.

Pairing

Set up in four steps.

  1. Deploy the Worker to your Cloudflare account (or ask for the done-for-you option).
  2. Add the one script tag to your site.
  3. Run JaegerRigAgent.exe on the PC you want to show and press Get key from site.
  4. Open your site. The panel shows Online within a few seconds.

Status colours

Reading the tray icon.

  • Green: online and reporting.
  • Orange: cannot reach the site, retrying.
  • Red: the key was rejected. Press Change key and pair again.
  • Grey: starting up.

Questions

Install questions.

Do I need to write any code?

No. One script tag is the whole install on your site. The app pairs itself with a button.

What happens when my PC is off?

The panel shows Offline after about 25 seconds without an update and keeps the last known specs, so visitors never see an error.

Can I put it in a specific place on the page?

Yes. Add the small data-jgrs-rig placeholder where you want it. Without it, the panel floats in the corner.
