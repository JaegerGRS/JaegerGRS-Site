Show your own PC or server on your website: specs, CPU, GPU and RAM load, all live. A tiny Windows app plus a Cloudflare Worker API, sold together.

Install

One line. No coding.

Add this single tag to your page and the live panel appears by itself. It updates every few seconds and works on phones and TVs.

<script src="/embed/rig-embed.js" defer></script>
  • Want it in a certain spot? Add <div data-jgrs-rig></div> where it should go. Otherwise it floats in the corner.
  • Options on the tag: data-title, data-theme="light", data-api.
  • On your PC: run the app, click Get key from site, done. No key to copy.
