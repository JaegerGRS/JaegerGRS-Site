Rig API · The kit

The kit and its limits.

What is included, how it protects the connection, and what it does not do.

Included

What you get.

  • The Worker source: a key-protected POST endpoint, a public GET snapshot and a Durable Object that stores the latest state.
  • JaegerRigAgent.exe, the Windows tray app, with Start with Windows and a key stored using Windows DPAPI.
  • rig-embed.js and rig-embed.css, the one-tag panel.
  • The setup guide, and help getting it running as agreed when you enquire.

Security

What it does.

  • Only a PC holding the pairing key can post updates. The Worker compares keys in constant time. On the PC the key is encrypted with Windows DPAPI for your account.
  • Updates are size limited and rate limited, and every value is whitelisted and cleaned before it is stored.
  • Specs sent: CPU, GPU and driver, memory, board maker and model, operating system build and storage totals, plus load figures. No files, personal data or network details.
  • Strict security headers on responses. Setup mode must be switched off by you after pairing, because it is not closed automatically.

The full review, including the gaps, is in the case study.

Limits, stated plainly: one PC reports to one site. The app is Windows only, and GPU statistics need an NVIDIA card with nvidia-smi. It is not built for large servers, many machines or heavy traffic, and it has not been independently audited. There is no uptime guarantee, and support is what we agree when you enquire.
