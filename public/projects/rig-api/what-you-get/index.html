Rig API · The kit

The whole kit.

Everything needed to show one PC or server on one small website.

Included

What you get.

  • The Worker API (GET snapshot, key-protected POST) and Durable Object, ready to deploy to your own Cloudflare account.
  • JaegerRigAgent.exe, the Windows tray app with Start with Windows and an encrypted key.
  • The front-end live panel: one script tag, no coding.
  • A setup guide and help getting it running.

Security

How it stays safe.

  • Only a PC holding the pairing key can post updates. The key is compared in constant time and stored encrypted on the PC for your Windows account only.
  • Updates are rate limited and size limited, and every value is cleaned before it is stored.
  • Only hardware names and load numbers are sent: no files, personal data or network details.
  • Strict security headers on every response, and setup mode is closed after pairing.
Limits, stated plainly: one PC reports to one site. Windows only for the app (NVIDIA GPU stats need nvidia-smi). It is not built for large servers, many machines or heavy traffic yet, and it comes without a guarantee of uptime or support level beyond what we agree when you buy.
