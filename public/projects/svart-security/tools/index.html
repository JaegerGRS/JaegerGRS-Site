Questions

Tool questions.

What do the status labels mean?

In development means work has started (svartsecurity.org calls Svart AI Building now). Planned means a roadmap entry only. Nothing is released. See the status key on the Projects page.

Is anything collected about me?

The stated policy is no tracking, ads or data collection. It is a promise, not an audited result, and no tool is released yet.

How is data protected?

The intended design is to encrypt data on your device with AES-256-GCM, a widely used standard. This is a design goal and has not been tested or audited for any Svart tool.
