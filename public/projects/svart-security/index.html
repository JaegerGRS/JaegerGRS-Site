Principles

What it stands for.

  • Encrypted by default. AES-256-GCM, with data encrypted on the device before it leaves.
  • No tracking. No ads. Ever. Zero telemetry, analytics, data collection or advertising.
  • Built for real people. One developer, building tools that just work without setup guides.
The website is live; the tools are in active development and features may change before launch. Status labels below mirror svartsecurity.org.
