Purpose

Privacy tools, built by one person.

Svart Security is my independent project to design a family of privacy-focused tools, from a browser to a password vault, and to publish them with a website and roadmap. I am the sole developer and maintain the website.

It shows how I plan and structure a large piece of software. It is not yet evidence of shipped security software, and this page says so plainly.

Approach

How I am building it.

Plan in the open

A public roadmap and a status label for every tool, so progress can be checked.

One tool at a time

The browser and AI assistant come first; the other eight tools are planned and not started publicly.

Claims follow evidence

Security statements here are labelled as design goals until a tool ships and has been tested.

Security design principles

Goals, not guarantees.

Each is the intended design. None is claimed as verified.

Design goal

Encrypt on the device

Data would be locked on your own device before it is stored or sent, so a server would hold only scrambled data. The plan uses a standard method called AES-256-GCM.

Policy

No tracking or ads

The stated policy is no analytics, advertising or data collection. It is a promise, not an audited result.

Design goal

Self-hosting option

The planned chat tool is meant to run on your own server, so you control where messages live.

Known limitations. No tool is released, so none has been tested by users or audited by an independent party. Encryption, no-logs, end-to-end and zero-knowledge wording on svartsecurity.org describes plans. Treat it as intent until a tool is released with evidence.
