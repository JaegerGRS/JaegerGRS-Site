Pipeline

From change to installer.

  1. A change is pushed to the GitHub repository.
  2. CI validates it, and an hourly health check keeps watching.
  3. The Windows MSI workflow builds an installer through Tauri.
  4. Scripted install, dev, run, build and clean commands make every run repeatable.

Questions

Engineering questions.

Does JAE need the cloud?

No. Local inference and local data are the default, and runtime data is never used as a cloud inference backend.

What does it run on?

Windows 10 and 11, with a Tauri shell and a local Python 3.12+ backend process managed by the Tauri runtime.
