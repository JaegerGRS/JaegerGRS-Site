Overview

What it is.

JAE is a desktop app for chatting with AI models that run locally, so prompts are not sent to a cloud service. The README states that runtime data is local and is not used as a cloud inference backend.

It is a prototype. The code and automated checks exist on GitHub, but I have not published an installer or release, so you cannot download a finished app yet.

Current state

What the repository shows today.

From the source and changelog on GitHub, checked on 15 October 2026. I have not run a release build myself for this page.

In the source code

  • A FastAPI backend with hardware detection, model selection by hardware tier, a model manifest, and health, system, models, settings and chat endpoints.
  • Streaming chat responses, and a llama.cpp inference provider.
  • A model download manager with a queue, progress, cancellation and checksum validation.
  • Encrypted, signed backups with create, verify and restore.
  • SQLite storage, and a React and TypeScript interface with 16 pages, including Chat, Models, System, Backup, Security and Settings.

Not yet shown or confirmed

  • A published release or installer. The GitHub releases page is empty.
  • Application screenshots. None are on this page yet.
  • That every interface page is complete. Some may be early scaffolding.
  • macOS or Linux support. The project targets Windows 10 and 11 only.

Architecture

How the parts fit together.

Tauri

The desktop shell. It hosts the interface and starts and manages the local backend, so there is no separate server to run.

Python backend

FastAPI, with hardware detection, model management, chat streaming, backups and SQLite. Python 3.12 or newer.

Local models

llama.cpp is the only inference provider in the code. The model manifest still contains a placeholder download URL and checksum.

Known limitations

Honest gaps.

  • Prototype: no release, installer download or screenshots yet.
  • The model manifest holds a placeholder download URL and checksum, so models are not downloadable out of the box.
  • The MSI build workflow exists but has never run, so an installer build is not yet proven in CI.
  • Backend tests cover core modules such as the API, backups, database, hardware detection and model download. The interface has a build check but no tests.

Related work

JAE and Personal AI.

JAE and the Personal AI project on JaeTheTech are separate codebases with the same aim: a private AI assistant on your own PC. JAE uses Python, FastAPI, llama.cpp and React inside Tauri. Personal AI uses Node.js, Express and Ollama, as a Tauri app or a PWA. They are two approaches to one idea, not two finished products.
