Focus

What it's built around.

  • Native Windows desktop delivery through Tauri and MSI installers.
  • Local inference and local data: runtime data is never used as a cloud inference backend.
  • GitHub as the source, release and update pipeline.
  • A native-first design: frontend plus a local backend process managed by the Tauri runtime.
