JaeTheTech · Project

Personal AI.

A local-first AI assistant for coding, market data, news and daily tasks, using local models through Ollama. It is described on jaethetech.com. Its source code is not public, so this page separates what the project states from what I can confirm.

Description on jaethetech.com ↗
Status
In development (listed as "Building Now" on its roadmap)
Source
No public repository found
Release
None found
Stack
Node.js, Express, WebSocket, Ollama; Tauri and PWA targets
Verification. The facts on this page come from the public jaethetech.com pages and its public repository. I have not seen the Personal AI code or a running copy, so features below are the project's own statements, not confirmed behaviour.

Local and external

What runs where.

The whole app is not offline, because live data has to come from outside.

Local

Model inference

AI chat and code assistance are stated to run on local models through Ollama, on the user's own PC.

Needs internet

Live market and news data

Gold and crypto prices and multi-source news can only come from external services, so these features need an internet connection. The data providers are not named publicly.

Unconfirmed

Where data is stored

The site says everything is kept local by default. Where conversations, settings and files are stored, and in what form, is not documented, so I am not claiming more.

Versions

Desktop, PWA and sync.

The project describes two ways to run it: a Tauri desktop build and a PWA that works on other devices. A WebSocket layer is described for syncing settings, conversations and files between devices on the same local network.

Its roadmap lists Tauri desktop polish and multi-device sync as milestones, so I treat both as work in progress. I cannot confirm that a finished desktop installer exists, and no release is published.

Status

What is implemented and what is not.

Stated as built

From the roadmap: a seven-agent hub (coding, trading, general, personal, news, image and builder), AI chat with local Ollama models and a self-editing builder agent.

Prototype or unconfirmed

Everything else is unconfirmed: live market data, WebSocket sync, Tauri polish and the "network privacy layer" and "MAC/UA randomisation" listed on the site. I have not verified any of them.

The Personal AI visual on jaethetech.com is an illustrative mock-up, not a screenshot of the application, so I have not reproduced it as evidence here.

Relationship

How it relates to JAE.

JAE, the Jaeger Adaptive Engine and Personal AI share an aim, a private AI assistant running on personal hardware, but they are separate codebases. Personal AI uses Node.js and Ollama. JAE uses Python, FastAPI and llama.cpp, and its source is public. I do not consider them two finished products.

Questions

About Personal AI.

Does it work offline?

Local chat is stated to use Ollama on the PC. Live market and news data need the internet, so the whole application is not offline.

Does my data leave my machine?

Local inference is stated to stay on the PC, but external data retrieval makes outgoing requests. Storage and what is sent are not documented, so I make no stronger claim.

Can I download it?

No release or public repository was found.
