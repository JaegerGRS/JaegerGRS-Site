Personal AI.

A self-editing AI assistant that handles coding, live market data, news and daily tasks. It runs entirely on local AI through Ollama and is built from scratch with no UI frameworks.

Questions

About Personal AI.

Does my data leave my machine?

No. It runs on local AI through Ollama and keeps everything local by default.

Is it a desktop app or a web app?

Both. It works as a Tauri desktop app or as a PWA on any device.

Which frameworks does it use?

None for the interface. It is built from scratch, with Node.js, Express and WebSockets behind it.
