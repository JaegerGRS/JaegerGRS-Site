Grey Signal · The build

What’s in the site.

A self-hosted website with its own Windows control app, Node engine and a Cloudflare version prepared for a future domain.

Features

Built end to end.

  • Multi-page layout: home, transmissions, ops, rig, about and contact.
  • A rig page that refreshes itself with specs, load and temperatures.
  • Responsive design, metadata, social cards and accessibility basics.
  • A Windows app (C#) that runs and manages the site, with an .msi installer.
  • A Node.js site engine for a PC or VPS, plus a Cloudflare Worker version (D1, email, live stats) ready for a future domain.
The rig page shares hardware details only: no personal information, files or network details. The self-hosted site runs over plain HTTP at an open IP address, so your browser may show a "not secure" notice.

Hosting

Three ways to run it.

  1. On this PC: free and private, and it can be shown to the world through a Cloudflare Tunnel that hides the home address.
  2. On Cloudflare: the Worker version with D1, email and live stats, online 24/7.
  3. On a rented server: the Node engine in Docker behind Caddy, for a VPS.

Questions

Build questions.

Why is the live site not on HTTPS yet?

It is self-hosted at an open IP address over plain HTTP while a proper domain is set up, so browsers show a not secure notice.

Does the rig page share personal data?

No. It shares hardware names and load numbers only: no personal information, files or network details.
