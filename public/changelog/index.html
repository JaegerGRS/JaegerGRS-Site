v0.3.015 OCT 2026

Redesign, real assets and standalone sites

  • New visual design with per-project accent colours, cards, breadcrumbs and reveal animations.
  • Added the real Grey Signal logo, banner and artwork, and direct links to every standalone site: Svart Security, Grey Signal, JaeTheTech and the JAE repository.
  • Added the Svart toolkit overview, the JaeTheTech Personal AI project and a JAE case study.
  • Worker now serves the whole site, including images, through Cloudflare static assets.
  • Live PC panel and secure contact form, both on the Worker with strict security headers and rate limiting.
  • JaegerRigAgent.exe: a 24 KB Windows tray app that pairs with the site using a key the site creates, starts with Windows and uses almost no CPU.
  • New Rig API product page with a one-line embed and pricing, made for small sites and servers only.
  • Works on phones, tablets, desktops and TVs; self-host mode for private testing.
