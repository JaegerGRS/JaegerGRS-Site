OVERVIEW

What this project
is about.

Svart Security is my independent security and privacy project, with a public website and a roadmap covering private AI, browsing, encrypted credentials and secure messaging.

The design direction is local-first: control should remain with the person using the software. The site explains the product vision while individual tools move through development. Marketing promises should not be confused with third-party security audits.
