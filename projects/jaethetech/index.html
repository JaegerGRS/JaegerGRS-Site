OVERVIEW

What this project
is about.

JaeTheTech is my broader technical website, covering web development, software experiments, security, hardware and ongoing projects.

The site showcases a deliberately lightweight, custom-built frontend. Its projects include local AI experimentation, cross-platform ideas, and development across JavaScript, Node.js, Rust and Tauri.
