OVERVIEW

What this project
is about.

Grey Signal combines a custom brand, a multi-page channel website, interactive elements and an experimental hardware telemetry page.

The website includes dedicated pages for videos, operations, about, contact and PC hardware. Its rig page is designed to fetch approved system information, with the intent to avoid exposing personal files or network details. The telemetry service itself is a separate component.
